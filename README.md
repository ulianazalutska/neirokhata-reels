# neirokhata-reels

Рілси Нейрохати: шаблон Remotion і студія для перегляду та налаштувань.

- Студія: https://ulianazalutska.github.io/neirokhata-reels/ (відкривається також із вкладки Instagram у дашборді)
- `src/` — сцени (`Reel.jsx`), набір елементів і стиль (`kit.jsx`), таймінг (`timeline.js`)
- `studio/` — сторінка студії (плеєр + налаштування)
- `public/` — пози Нейрика, звуки, озвучка
- Рендер локально: `npm run render`
